# D&D 第5版「無料ベーシック・ルール」5文書の比較

D&D第5版の無料ルールは、**2014年ルール（5e）**と**2024年改訂ルール（5.5e）**というルール世代の違いに加え、**同じ2014年ルールでもPDFとD&D Beyondのオンライン版では収録範囲が異なる**。この2つを混同しないため、以下の5文書を区別する。

1. **2014年ルール・日本語版**：プレイヤー用 Basic Rules v0.3 の翻訳（2015年公開）
2. **2014年ルール・英語版 v0.1**：2014年の初期PDF
3. **2014年ルール・英語版 v1.0**：2018年11月の統合PDF
4. **2014年ルール・D&D Beyondオンライン版**：12クラスを読める無料ページ（**このキャンペーンの基本参照先**）
5. **2024年改訂ルール・D&D Beyondオンライン版**：現行の改訂ルールの無料ページ

> **注意**：ここで比較するのは「無料公開された文書の収録内容」であり、各世代の有料『Player's Handbook』全体の収録内容ではない。収録数は掲載媒体や更新時点によって異なる。以下の数値は、各節で挙げた資料に対応する。

（2026-11-10 改訂）

---

## 1. 2014年ルール・日本語版（v0.3の翻訳）

- **正体**：英語版 *Player's Basic Rules Version 0.3* の日本語訳。日本語版PDFの冒頭に原典の版として **Version 0.3** と明記されている。
- **公開経緯**：日本語のプレイヤー用PDFは2015年9月、DM用PDFは同年11月にホビージャパン経由で無料公開された。2024年6月から日本公式サイトで再配布されている。PDF冒頭の「Release: August 12, 2014」は**英語原典側の記載**で、日本語版の公開日ではない。
- **収録範囲（プレイヤー用）**：Cleric / Fighter / Rogue / Wizard の4クラス（それぞれ基本的な1サブクラス）、Dwarf / Elf / Halfling / Human の4種族、約120種の呪文。プレイヤー用は114ページ。
- **注意**：DruidやMonkのクラス本文はこのPDFには載っていない。マルチクラス・特技の詳細や追加クラスは『Player's Handbook』等の別資料が必要。
- **入手**：[日本公式サイトのツール一覧](https://dnd-jp.com/tools/)／[プレイヤー用日本語版PDF](https://dnd-jp.com/wp-content/uploads/2024/06/DnD-PlayerBasicRules-wotc2024-1.pdf)。

スターター・セットに付属する簡易ルールブックと、この114ページの無料PDFは別の資料である。

## 2. 2014年ルール・英語版 v0.1（初期PDF）

- **正体**：2014年7月に無料公開された初期の *Player's Basic Rules*。プレイヤー用PDFは2014年7月、DM用PDF（Dungeon Master's Basic Rules v0.1）は2014年8月に、それぞれ公開された。
- **プレイヤー向け選択肢**：4クラス（Cleric / Fighter / Rogue / Wizard）と4種族（Dwarf / Elf / Halfling / Human）。
- **亜種族**：Dwarf / Elf / Halfling は各2亜種族を掲載する一方、**Humanに亜種族はない**。
- **特技・マルチクラス**：プレイヤー用PDF第6章では特技とマルチクラスの概要に触れているが、個別の特技データやマルチクラスの実用ルールは掲載していない。
- **DM用の収録内容**：*Dungeon Master's Basic Rules v0.1* の印刷ページ2〜52（Monsters）に載るモンスターのデータ項目を**各1件で計158件**、同53〜55（Nonplayer Characters）のNPCデータ項目を**各1件で計10件**と数える（NPCは158件に含めない）。この集計は[BoardGameGeekの版別収録一覧](https://boardgamegeek.com/wiki/page/Dungeons_and_Dragons_Basic_Rules_%28version_history%29)に基づく。掲載範囲と個別データの一次資料は[WotC公式DM用PDF](https://media.wizards.com/2014/downloads/dnd/DMDnDBasicRules_v0.1.pdf)。
- **日本語版との関係**：日本語版は **v0.1そのものの翻訳ではなく、v0.3の翻訳**である。

初期PDFの版別収録内容は[BoardGameGeekの版履歴一覧](https://boardgamegeek.com/wiki/page/Dungeons_and_Dragons_Basic_Rules_%28version_history%29)にまとめられている（ファン作成の二次資料）。

## 3. 2014年ルール・英語版 v1.0（2018年11月PDF）

- **正体**：2018年11月公開の *D&D Basic Rules, Version 1.0*。プレイヤー向けとDM向けを1つのPDFにまとめた。
- **収録範囲**：PDFの目次にあるクラスは **Cleric / Fighter / Rogue / Wizard の4つ**、種族は **Dwarf / Elf / Halfling / Human の4つ**。このPDFにMonkやDruidのクラス本文は含まれない。
- **特技・マルチクラス**：第6章に概要はあるが、2014年PHBに載る特技・マルチクラスの全詳細を提供するものではない。
- **D&D Beyond版との関係**：後述のD&D Beyond「Basic Rules (2014)」は**別の公開媒体**であり、収録クラス数も異なる。
- **入手**：[Wizards of the Coast公式PDF](https://media.wizards.com/2018/dnd/downloads/DnD_BasicRules_2018.pdf)（表紙および目次を参照）。

## 4. 2014年ルール・D&D Beyondオンライン版（キャンペーンの基本参照先）

- **正体**：D&D Beyondの **[Basic Rules (2014)](https://www.dndbeyond.com/sources/dnd/basic-rules-2014)**。2018年v1.0 PDFとは収録範囲が異なるオンライン資料で、SRD 5.1に対応する選択肢も含む。
- **収録範囲**：**12クラス**（Druid、Monkを含む）と**9種族**を掲載。クラス本文では各1種のサブクラスの詳細を閲覧できる（下表）。

2026年11月10日に[D&D Beyondの2014年版「Classes」](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/classes)で確認したサブクラス本文：

| クラス | 掲載サブクラス | クラス | 掲載サブクラス |
|---|---|---|---|
| Barbarian | Path of the Berserker | Bard | College of Lore |
| Cleric | Life Domain | Druid | Circle of the Land |
| Fighter | Champion | Monk | Way of the Open Hand |
| Paladin | Oath of Devotion | Ranger | Hunter |
| Rogue | Thief | Sorcerer | Draconic Bloodline |
| Warlock | The Fiend | Wizard | School of Evocation |

※各クラスの説明文にはこれ以外のサブクラス名も登場するが、リンク先の無料掲載本文で個別の特徴が説明されているものを挙げた。
- **特技**：2014年ルールの特技 **[Grappler](https://www.dndbeyond.com/feats/10-grappler)（1種）**を掲載。掲載内容はリンク先のD&D Beyond上で確認できる。
- **ルール世代**：2014年版（5e）。能力値の種族由来の上昇、クラスごとに異なるサブクラス取得レベル、2014年版の不意打ち・疲労のルールが適用される。
- **このキャンペーンとの関係**：Karin（Monk）、Wren（Druid）、Wizardの2014年版クラス規則を**無料で参照する先**はこのオンライン版。2018年PDFにMonkやDruidが載っていないことは、2014年ルールにそのクラスが存在しないという意味ではない。

必要な個別ルールは[クラス一覧](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/classes)から確認する。

## 5. 2024年改訂ルール・D&D Beyondオンライン版（5.5e）

- **正体**：2024年9月に公開された改訂ルールの無料版。その後内容が拡充され、現在は **[D&D Beyond Basic Rules](https://www.dndbeyond.com/sources/dnd/br-2024)** として参照できる。2014年ルールとは**ルールそのものが異なる**。
- **現行オンライン版の収録範囲**：**12クラス、9種族（Species）、17種の特技（Feats）**。17特技はOrigin / General / Fighting Style / Epic Boonの合計であり、**全部が1レベルから背景によって取得できるわけではない**。
- **2014年版との主な違い**：
  - 能力値の上昇値は原則として**背景**から得る。背景に **Origin Feat** が付く
  - 「Race」から「Species」へ用語を変更
  - サブクラス選択開始は**全クラス3レベル**
  - **Weapon Mastery**（Cleave、Topple、Nickなど）を導入
  - **不意打ち**：2014年版の「最初のターンは移動・アクション不可、ターン終了までリアクション不可」から、2024年版では「イニシアチブ判定に不利」へ変更
  - **組み付き・押しやり**：2014年版の対抗能力値判定から、2024年版では主にセーヴィング・スロー方式へ変更
  - **Cure Wounds**：1レベル呪文で **2d8＋呪文発動能力修正値** を回復
  - **疲労**：2014年版の段階別効果表から、2024年版では1段階につき **D20 Testに−2、移動速度に−5フィート**（6段階で死亡）へ変更
  - **Inspiration** は **Heroic Inspiration** に変更

参照：[2024年版・種族を選ぶ](https://www.dndbeyond.com/sources/dnd/br-2024/creating-a-character)／[2024年版・特技一覧](https://www.dndbeyond.com/sources/dnd/br-2024/feats)。

## まとめ

- **日本語版は v0.3 の翻訳**。公開年は2015年で、PDF記載の英語原典側の日付とは分けて扱う。
- **2018年の v1.0 PDF は4クラス**。Monk / Druidを読める **D&D Beyondの2014年版オンライン資料（12クラス）とは別**。
- **このキャンペーンはD&D Beyond Basic Rules (2014)を基本参照先とする**。追加資料やDM裁定を使う場合は別途明示する。
- **2024年改訂版はルール世代が異なる**。同名の能力や呪文にも、2014年版と異なる仕様がある。
